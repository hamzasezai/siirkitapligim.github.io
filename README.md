🌟 Project Overview

siirkitapligim.github.io is a static website that showcases a collection of poems and writings. It is built using simple HTML and CSS, and designed to be hosted via GitHub Pages for easy access and presentation of classic and modern poetry.

🚀 Features

📄 Multiple HTML pages for poems, authors, and sections

🎨 Custom styling with CSS

🎧 Audio and multimedia sections (if present in FOTOĞRAFLAR / Sesler folders)

🌐 Works as a fully static website deployable on GitHub Pages
